# 🌐 Rayen Hajjem - Personal Portfolio Website

Welcome to my personal portfolio website! This website showcases my background, technical skills, projects, and research interests in Artificial Intelligence, Internet of Things (IoT), Embedded Systems, and Quantum Computing. It serves as a central hub for my academic achievements, professional experience, and personal projects.

## 📖 About

This portfolio was designed to present my work in a clean, modern, and responsive interface. Visitors can learn more about me, explore my projects, view my research interests, and easily get in touch.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Interactive About Me section
- Projects showcase
- Research interests
- Contact page
- Smooth scrolling and navigation
- Clean and modern UI
- Fast loading performance

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/rayenhajjem-blip/portfolio.git
```

Navigate to the project directory:

```bash
cd portfolio
```

Since this is a static website, simply open `index.html` in your browser or use a local development server such as VS Code Server.
